# 奇性扣除（Singularity Subtraction）：钝前缘 TSD 外区求解的正则化

> 用途：让 pyTSFoil 的外区 SLOR 求解在圆前缘处**数值干净**，即数值解真正等于
> MAE 理论里的外区渐近解 $\phi_1$，从而 $\Gamma$、激波位置、远场可信。
> 这是 `TSD_leading_edge_correction.md` 第 8 节里"正则化外解"那一步的展开。
>
> 一句话定位：**奇性扣除负责全局调理（让外解干净），composite 负责鼻部物理 $c_p$。两者互补，不可互相替代。**

---

## 1. 原因（为什么需要）

### 1.1 根因：小扰动假设本身在鼻部失效

**这不是网格收敛问题，是模型层面的失效。** 圆前缘 $ct(x/c)\sim 2h(cx)^{1/2}$，切向 BC 斜率 $F'_{u,l}\sim\pm h c^{1/2}x^{-1/2}\to\infty$。鼻部真实流动连续滞止：扰动速度

$$u\to -U_\infty\ (\text{驻点总速为零}),\qquad |v|\ \text{很大},$$

均为 $O(U_\infty)$——推导 KG 方程所依赖的 $u,v\ll U_\infty$ 在此**被彻底破坏**。而 TSD 自身的奇异解还**过冲**物理驻点：对称首项

$$c_p\sim +C\,x^{-1/3}\to+\infty\quad\Longrightarrow\quad u\to-\infty\ (\text{过度滞止}),$$

比 $u=-U_\infty$ 更离谱。

### 1.2 非物理前缘速度势污染全场

后果**不止鼻部不准**。这个非物理前缘速度势经两条通道污染**全场**：

1. **非线性系数 / 类型判别**：$(\gamma+1)\phi_x$ 在鼻部 $\to\infty$，喂进 Murman–Cole 判别与松弛，鼻后播下伪超声速点、振荡。
2. **环量 $\Gamma$（主通道）**：Kutta 是在**含被污染鼻区的整个场**上确定 $\Gamma$ 的，于是 $\Gamma$ 被系统性带偏；偏掉的 $\Gamma$ **刚性抬高整个环量场**，**上表面（吸力面）$u$ 过大**最为明显。

**网格加密救不了**：细化只会让你收敛到那个鼻部破坏模型、$\Gamma$ 已带偏的奇异解。因此这不是收敛性问题，而是必须**在求解过程中就把鼻部扰动量控制住**的问题。

### 1.3 与 composite 的分工

§6 的 composite 默认喂进去的 $c_{p\text{TSD}}$ 与 $\Gamma$ 已干净；若外解被上述机制污染，composite 就建在坏数据上。**分工**：

- **奇性扣除** = 保证外解与 $\Gamma$ 干净（全局）；
- **composite** = 给出鼻部物理 $c_p$（局部）。

二者缺一不可。注意奇性扣除把巨大的鼻部部分放进解析的 $\phi_s$，使数值未知量 $\phi_r$ 光滑、且 $\Gamma$ **只由 $\phi_r$ 读取**（$\phi_s$ 对称无跳跃，§2.2）——这正是切断"鼻部 → $\Gamma$ → 全场"污染链的关键。

## 2. 原理

### 2.1 基本分解

把外区未知量拆成"解析奇异部分 + 光滑余项"：

$$\phi_1=\phi_s+\phi_r.$$

- $\phi_s$：**解析已知**，携带鼻部全部奇异行为；不进网格离散。
- $\phi_r$：光滑、边界条件有界，**只对它做数值求解**。
- 重构 $\phi_1=\phi_s+\phi_r$ 后再算 $c_p$、$\Gamma$。

### 2.2 只有"厚度（对称）"斜率是奇异的 ★

鼻部 $x\to0$ 各项行为：

| 贡献 | 近鼻行为 | 斜率 |
|---|---|---|
| 厚度 $ct(x/c)$ | $\sim 2h(cx)^{1/2}$ | $\sim h c^{1/2}x^{-1/2}$ **（奇异）** |
| 弯度 $C_a(x)$ | $\sim a_1 x$ | $\sim a_1$（有界） |
| 迎角 $-Ax$ | $-Ax$ | $-A$（有界） |

所以 $\phi_s$ **纯对称（厚度）**，不携带环量。直接推论：

$$\boxed{\ \Gamma\ \text{完全由}\ \phi_r\ \text{产生}（\phi_s\ \text{无跳跃）}\ }$$

环量与奇性扣除**解耦**——这是该方法干净的关键。

### 2.3 陷阱：线性 / 不可压扣除是无效的 ★★

直觉上想用一个不可压（Laplace）或 Prandtl–Glauert 的 $\phi_s$ 去匹配 $x^{-1/2}$ 的边界斜率。**不行**，原因是指数不自洽：

- 任意**线性**调和型 $\phi_s$，其边界斜率 $\phi_{s\tilde y}\sim x^{-1/2}$ 必然伴随面速 $\phi_{s,x}\sim x^{-1/2}$（解析函数两个分量同阶奇性），于是 $\phi_{s,xx}\sim x^{-3/2}$。
- 代入 KG 方程 $[K-(\gamma+1)\phi_x]\phi_{xx}+\phi_{\tilde y\tilde y}=0$，线性项 $K\phi_{s,xx}\sim x^{-3/2}$ 变成**场内强迫源**。
- 结果：把一个 $x^{-1/2}$ 的**边界**奇性，换成了 $x^{-3/2}$ 的**场**奇性——**更糟**。

物理根源：真实跨声速鼻部面速是 $x^{-1/3}$（比不可压薄翼的 $x^{-1/2}$ **更弱**），正是 KG 的非线性项 $(\gamma+1)\phi_x\phi_{xx}$ 把 $x^{-1/2}$ 软化成 $x^{-1/3}$。任何线性 $\phi_s$ 都给不出 $x^{-1/3}$，必然过扣。

### 2.4 正确的 $\phi_s$：跨声速鼻部相似解

唯一自洽的选择是 MAE 外区**首阶鼻部相似解**本身：

$$\phi_s=\chi(x,\tilde y)\cdot\frac{\tilde y^{4/7}}{\gamma+1}\,f(\xi),\qquad \xi=\frac{x}{\tilde y^{6/7}},$$

其中 $f$ 满足非线性 ODE $\big(f_\xi-\tfrac{36}{49}\xi^2\big)f_{\xi\xi}-\tfrac{30}{49}\xi f_\xi+\tfrac{12}{49}f=0$，由 hodograph 参数 $\sin\alpha\ (|\alpha|\le\alpha_3=80.40878^\circ)$ 给出（JFM 式 19/28/29/30）。它的好处：

- 满足 KG 的**非线性首阶平衡** ⟹ $L[\phi_s]$ 只剩高阶（**有界**）残量，没有 §2.3 的强迫陷阱。
- 面速 $\sim x^{-1/3}$（正确），边界斜率 $\phi_{s\tilde y}(x,0)$ 自动复现 $x^{-1/2}$ 的厚度部分（相似解本就按 BC 7b 构造）。
- ⟹ 余项 $\phi_r$ 的边界斜率 $F'-\phi_{s\tilde y}$ **有界**，$\phi_r$ 场**光滑**。

### 2.5 窗函数 $\chi$

相似解是**局部**的（只在鼻区有效，不满足全弦 BC、远场、Kutta），故须乘平滑窗 $\chi$：鼻区内 $\chi=1$，到 $x_{\rm match}$（数个 $R_c$，落在外解已良好的匹配环内）外 $\chi=0$。强迫被限制在 $\chi$ 过渡环内，且有界。

## 3. 实现方案（对接 SLOR 主循环）

### 3.1 一次性预备 $\phi_s$

$\phi_s$ **不依赖解**，由几何（$h,c$）与 $\gamma$ 完全确定，故离线计算一次：

1. 复用内区求解的 hodograph 基础设施，对 $\sin\alpha\in[-\alpha_3,\alpha_3]$ 制 $f(\xi),\ f'(\xi)$ 表（与 `inner_parabola.py` 共享）。
2. 选窗 $\chi(r)$，$r$ 为到鼻点的距离（以 $R_c$ 归一），在 $r_1\!\sim\!2R_c$ 与 $r_2\!\sim\!(\text{几})R_c$ 间平滑由 1 降到 0。
3. 在 pyTSFoil 网格上预存解析量：$\phi_s,\ \phi_{s,x},\ \phi_{s\tilde y}$（及做 Murman–Cole 需要的 $\phi_{s,x}$）。

### 3.2 φ_s 影响的求解环节（完整清单）

**总原则**：存储/更新的未知量改为光滑的 $\phi_r$；算子一律作用在 $\phi_{\rm tot}=\phi_s+\phi_r$ 上；$\phi_s$ 解析预置、窗到鼻区（在 TE 与远场前归零）。这样奇异部分活在解析的 $\phi_s$ 里，网格只表示光滑的 $\phi_r$。下面逐环节列出 $\phi_s$ 进入哪里、怎么进、起什么作用。

**A. 控制方程 / 离散算子**

| 环节 | 如何受 $\phi_s$ 影响 | 作用 |
|---|---|---|
| 非线性系数 $A=K-(\gamma+1)\phi_x$ | 改用 $\phi_{{\rm tot},x}=\phi_{s,x}+\phi_{r,x}$；鼻区由解析 $\phi_{s,x}$ 主导 | 系数取解析真值，不靠网格分辨 |
| $\phi_{xx}$ 项 | 邻列 $\phi_s$ 进 RHS，本列经 $A$ 进 DIAG | $\phi_s$ 作为已知量参与 x 二阶差分 |
| 窗过渡区强迫 | $L[\chi g]\approx(\nabla\chi\ \text{项})$，仅落在 $r_1\!\sim\!r_2$ 过渡环，有界 | 加性 RHS 源，局部有界（窗化的代价） |

**B. Murman–Cole 类型判别**

判别用 $\operatorname{sign}\!\big(K-(\gamma+1)\phi_{{\rm tot},x}\big)$。鼻区由**解析、无截断误差**的 $\phi_{s,x}$ 驱动 ⟹ 不再因分辨不足把过度滞止误判成 sonic/shock 点、不播伪超声速点。这是切断 §1.2 第 1 条污染通道的环节。

**C. y 向三对角装配（`DIAG/SUB/SUP/RHS`）**

稀疏结构（模板/带宽）不变；变的是系数值与右端项：

| 数组 | 是否变 | 说明 |
|---|---|---|
| `SUB`/`SUP` | 不变 | 来自 $\phi_{\tilde y\tilde y}$（常系数、纯 y） |
| `DIAG` | 变（值） | 含系数 $A$，而 $A$ 现含 $\phi_{s,x}$ |
| `RHS` | 变（值） | 加入：邻列 $\phi_{s,xx}$ 贡献 + 缝面斜率扣除项 + 窗过渡区强迫 |

> Numba：把 $\phi_s,\phi_{s,x},\phi_{s\tilde y}$（及若用显式强迫则 $\phi_{s,xx}$）作为**只读数组**传入扫掠核；它们一次算好、迭代中不变。

**D. 边界条件**

| BC | 如何受 $\phi_s$ 影响 | 说明 |
|---|---|---|
| 物面斜率（缝，$j\!=\!2$ 行） | $F'(x_i)\to F'(x_i)-\phi_{s\tilde y}(x_i,0)$ | 奇异厚度斜率被扣，$\phi_r$ 斜率**有界**（§2.2） |
| 尾迹跳跃 / 环量 $\Gamma$ | **不变**，$\Gamma$ 只由 $\phi_r$ 跳跃读出 | $\phi_s$ 对称且窗外为零 ⟹ 零跳跃；切断 §1.2 第 2 条污染通道 |
| 尾缘 Kutta | **不变** | 须保证窗在 TE 前归零，$\phi_s|_{\rm TE}=0$ |
| 远场 | **不变** | $\phi_s$ 窗外为零 |

**E. 后处理**

| 环节 | 如何受 $\phi_s$ 影响 |
|---|---|
| $c_p$ 重构 | $c_p=-2\delta^{2/3}\big(\phi_{s,x}+\phi_{r,x}\big)$；鼻区那段**不直接用**（交给 §6 composite），匹配区外 $\phi_s\to0$ 故 $c_p$ 即真外解 |
| 载荷积分 | 用重构 $c_p$ + composite 后再积分 |

**F. 迭代控制**

| 环节 | 如何受 $\phi_s$ 影响 |
|---|---|
| 初值 | 只给 $\phi_r$ 初值（$\phi_s$ 已解析预置） |
| 残差 / 收敛判据 | 监控 $\phi_r$；残差不再被奇性主导，收敛更干净 |
| SOR 松弛 | 松弛因子作用在 $\phi_r$ 更新上 |

**小结**——按改动性质分两类：

- **实质改动（值变）**：非线性系数 $A$、`DIAG`/`RHS`、缝面斜率 BC、$c_p$ 重构。
- **形式不变、仅改用 $\phi_{\rm tot}$ 评估**：MC 判别（鼻区由 $\phi_{s,x}$ 主导）；而 $\Gamma$、Kutta、远场因 $\phi_s$ 在那里恒为零，**数值上不变**——保护正是来自"大扰动只存在于对称且窗化的 $\phi_s$ 中"。

### 3.3 收益

- 缝面通量有界 ⟹ SLOR 迭代鼻区不再被注入大扰动，$\Gamma$/激波/远场 **mesh-converged**。
- 类型判别由解析 $\phi_{s,x}$ 主导 ⟹ 鼻后不再误判伪超声速点。
- 网格表示的是光滑 $\phi_r$ ⟹ 外场**网格无关**。

### 3.4 与 composite 的衔接

奇性扣除给出可信的外场与 $\Gamma$；§6 的 composite 仍负责鼻部物理 $c_p^*$。二者用的 $f(\xi)$ 同源（外区相似解的远场正是内区抛物线问题所匹配的对象），可共享同一张表。流程：

```
几何 → φ_s（解析，一次）
     → SLOR 解 φ_r（干净）→ φ_tot, Γ, c_pTSD
     → composite（§6）→ 鼻部修正 c_p
     → 重积分载荷
```

### 3.5 验证

1. **网格收敛**：对比有/无扣除时 $\Gamma,\ C_l$ 随网格的行为——扣除后应变为网格无关。
2. **匹配环检查**：扣除后外区 $c_{p\text{TSD}}$ 在数个 $R_c$ 处应光滑、网格无关。
3. **基准**：Joukowski $\delta=0.10,\ M_\infty=0.8,\ \theta=0^\circ/1^\circ$（JFM 图 7）；NACA0012 $M_\infty=0.8$（CASJ 图 3）。

## 4. 决策表：用哪一档

| 方案 | 成本 | 何时用 |
|---|---|---|
| 鼻部网格聚类 | 最低 | **仅辅助**：减小鼻区截断误差、缓解伪超声速点；但**不约束扰动量、不保护 $\Gamma$**，无法替代扣除（细化只会收敛到被污染的奇异解）。可与扣除并用。 |
| **奇性扣除（本文档）** | 中 | **基准做法**。切断鼻部对 $(\gamma+1)\phi_x$、类型判别、$\Gamma$ 的污染，使外解与 $\Gamma$ 网格无关且可信。 |
| 全耦合分区（内区 patch ⇄ 外区双向耦合） | 最高 | 扣除仍不足时；把 §7 内区解作为鼻部子域与外区在 patch 边界耦合，而非后处理。 |
